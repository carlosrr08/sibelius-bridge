# Layout rules

Draft defaults from standard part-preparation practice (MOLA guidelines, Gould "Behind Bars").
Edit freely: change a value, delete a rule, add your own. Claude checks every part against this
file and reports anything it could not fix.

## Page and size

- Paper: A4 portrait for score and parts.
- Part staff size: 7.0 mm (allowed 6.5 to 7.5).
- Score staff size: as large as the page allows, but never below 4.5 mm.
- First page: title block on top, part name top left, more top margin than later pages.

## Page turns (parts)

- Page 1 is a right-hand page. Turns happen after pages 1, 3, 5, ...
- Every turn needs rests: the player must have at least 2 seconds free at the turn, measured at
  the tempo there. Prefer turns at the start of a long rest.
- No turns in the middle of a phrase, even if it fits.
- If no usable turn exists: first try reflowing systems, then split a multirest, then a blank
  left page so the passage opens as a two-page spread. Report it if none of these work.
- Two-page or three-page parts should need no turns at all.

## Systems

- No single-bar systems except for very dense bars.
- Similar passages get the same number of bars per system.
- Prefer system breaks right before rehearsal marks, key changes and tempo changes.
- Last system of a page: full width, never a stub.
- Last page: at least 1/3 full. Reflow earlier pages instead of leaving one system alone.

## Multirests

- On in parts, off in the score.
- Split at rehearsal marks, key, meter and tempo changes (Sibelius does this by default).
- Cue notes before an entrance after a long rest (8 bars or more). Claude flags missing cues;
  adding them is a manual step for now.

## Vocal parts

- Dynamics and hairpins above the staff, lyrics alone below.
- Staff size 6.5 mm (choral octavo range), more space between systems than instrumental parts.

## Spacing and collisions

- Staves spread evenly when a page is at least 2/3 full.
- No collisions between dynamics, text, slurs, hairpins and notes. Checked visually in the PDF.

## Open questions (decide per project)

- Film sessions: bar numbers on every bar in parts, or every system?
- Page breaks in the score at rehearsal marks, or free?
- Letter or 9x12 inch for any US work?
